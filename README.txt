 Card Game using C++ and SDL3.
The project includes 4 solitaire variants: Klondike, Pyramid, Spider and Freecell.

This project is still in development. See TODO for more info.

Requirements
- C++17 compiler
- CMake 3.20+
- SDL3, SDL3_image, SDL3_ttf installed


Make sure to change the include and link paths in the CMakeLists.txt as well as the assets in rendering if needed.
